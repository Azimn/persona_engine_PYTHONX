PersonaConsole Python Lab

Shape and human-test the Persona Engine before selected polish is ported back toward the low-hardware C99/P99 console line.

Start Human Testing

The console page works after the local Python UI server is running.

1. Start the local server

From this repository, run persona-engine-ui or start Uvicorn with the package entry point.

2. Open the human-test console

Open http://127.0.0.1:8012/, choose a cartridge, run the session, and capture the report while the exchange is fresh.

Advanced and developer options
  1. Install the package with python -m pip install -e ..
  2. Run tests with python -m pytest persona_engine/tests -q.
  3. Run the simulator with persona-engine-sim --help.
  4. Run the UI with persona-engine-ui.
  5. Optional local model testing is available through Ollama. Mock mode remains dependency-free.
