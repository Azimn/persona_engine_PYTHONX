# Non-USER_TOLD Memory Consumer Audit

This audit records the production consumers that determine semantic residency. It does not assign a global memory capacity.

| Family | Production producer | Current consumers | Reconstruction status | Production residency conclusion |
| --- | --- | --- | --- | --- |
| `USER_TOLD` | canonical user input writeback | ordinary turn retrieval; unresolved-history conduct; reflection evidence | wording recoverable from canonical cold biography; original causal metadata is not reconstructed | retain current causally active unresolved evidence; allow inactive autobiography to page from cold biography |
| `OBSERVED` | `OrganismTick` significant sensorium transitions and bounded observation paths | ordinary turn retrieval; reflection top-k when salient/unresolved | no first-person cold reader; some underlying sensor roots are replayable but resident `MemoryUnit` experience/salience is not reconstructed | remain resident |
| `REFLECTION` | `_trigger_reflection()` | ordinary turn retrieval; autobiographical evidence that the subject formed the reflection | downstream earned trait and relationship belief survive separately, but the first-person reflection episode is not cold-reconstructable | remain resident |
| `INFERRED` | no current production `MemoryUnit` constructor | none | no archive contract | no resident budget role today; fail closed if introduced |
| `CORE_IDENTITY` | no current production autobiographical `MemoryUnit` constructor | identity is owned by cartridge/self-model/identity ledger instead | authored identity is available outside autobiographical memory | no resident budget role today; fail closed if such memories appear |

`HistoryDecisionEvidence` requires unresolved retrieved memory with relationship relevance at least `0.40`. Production `OBSERVED` memories currently use relationship relevance `0.30` for `user_absence` and `0.10` otherwise, so they do not directly activate that conduct adapter. They can still affect ordinary retrieval and reflection, and therefore cannot be declared disposable.

The critical distinction remains content recoverability versus causal or experiential recoverability. A downstream trait or world state surviving does not prove that the subject's first-person experience can be discarded.
