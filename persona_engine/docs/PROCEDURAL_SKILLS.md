# Procedural Skills

`SkillStore` owns bounded context-sensitive competence. Supported objective
practice changes competence more than inferred practice. Automaticity lowers
effort in matching contexts and creates a bounded misapplication penalty in
poor contexts.

Skills enter synthesis as candidates and cannot override identity, safety,
World Authority, or urgent intentions. Habits remain independent tendencies;
successful behavior can improve skill without becoming habitual, and a
repeated habit can persist despite weak competence.
