# Project Wayfarer Charter

Project Wayfarer is the next development line of PythonX. Its purpose is to turn the existing persona engine into a reference architecture for a portable, persistent simulated individual whose identity and lived continuity remain external to any particular language model, host application, device, or vendor.

## Primary objective

The character must remain the same continuing individual across renderer swaps, process restarts, host migrations, long periods of inactivity, social pressure, and changes in hardware or model capability.

The character is defined by authored phenotype plus governed lived state. The language model is a replaceable semantic and linguistic organ. It may help interpret, propose, plan, or realize speech, but it does not own canonical identity, biography, relationships, commitments, beliefs, goals, action authority, or continuity.

## Architectural invariants

1. One continuing individual has one canonical causal history.
2. Natural language never receives direct write authority over identity or goals.
3. Social influence is allowed, but must be mediated through the character's own values, relationships, motives, evidence, and plasticity.
4. Renderer output is noncanonical unless an external authority separately establishes the same proposition as fact.
5. Objective world facts are created only by World Authority or explicitly approved host channels.
6. Subjective interpretations may be wrong, but must remain source-traced and cannot silently become objective truth.
7. Character development is allowed, but significant change must be bounded, evidence-backed, and attributable to lived history.
8. Host capability and character willingness are separate gates. A host may allow an action the character refuses, or forbid an action the character wants.
9. Multiple simultaneous interfaces are acceptable. Multiple independent writers to one canonical individual are not.
10. A copied character that accumulates a different history becomes a branch/descendant rather than a mergeable continuation of the original.
11. The character kernel must retain deterministic and offline-capable behavior. Neural generation is optional.
12. Hardware cost of the character kernel and hardware cost of the renderer must always be measured separately.
13. Rich portable character data may compile into a smaller runtime projection. Unsupported portable fields must be preserved, not destroyed.
14. No cognitive subsystem enters the minimum runtime without measurable benefit under ablation testing.

## Interoperability objective

`.snp` will evolve toward a portable character source format. A MatrAIx-compatible phenotype layer may provide a shared descriptive vocabulary, but Wayfarer remains responsible for identity ownership, developmental state, autobiographical continuity, relationships, commitments, authority, social influence, and causal state transitions.

## Long-term execution targets

The same individual should eventually be able to run through a no-model renderer, a small local model, a larger local model, a frontier model, a mobile/edge host, a game NPC host, and a low-resource C/P99-compatible runtime.

## Development rule

PythonX is the semantic reference laboratory. P99-next will be a later constrained implementation of frozen Wayfarer contracts, not a line-by-line port of Python code.
