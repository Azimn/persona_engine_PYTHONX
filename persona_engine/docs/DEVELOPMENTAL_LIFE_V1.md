# Developmental Life v1

Developmental Life extends existing ownership rather than adding another
executive:

```text
experience -> meaning -> synthesis -> action -> outcome
           -> evidence links -> memory connections -> skill/ritual/expectation
           -> slow cartridge-authorized earned-trait evidence
```

Explicit objective links may challenge autobiographical meaning. Self-monitor
still determines whether contradiction is noticed. Current meaning, learned
connections, skills, relationship expectations, and rituals enter the existing
bounded synthesis as influences. `ActionDecision` remains the sole action
owner.

All stores are bounded: 1,024 evidence links, 2,048 status events, 512 use
outcomes, 4,096 connections, 512 episodes, 128 skills, and 32 expectations and
rituals per relationship. Renderer prose and judge scores never update them.

Skills represent competence. Habits represent selection tendency. Rituals
represent repeated relationship-specific interaction structure. These remain
separate even when they concern similar behavior.
