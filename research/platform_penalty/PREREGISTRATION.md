Frozen before implementation and complete A/B/C results. Audit-only routing and UUID observations already exist and are declared development evidence. This is a pilot, not an adequately powered confirmatory study.

## Conditions and validity

A uses the strongest existing ordinary .snp subject-policy path, CharacterAgent.say, without graph effects. A0 separately measures the frozen FutureDuckHost, because audit found it bypasses that existing decision path. A0 is not substituted for A to inflate graph benefit.
B uses the same Wayfarer transition, interpretation, memory, rendering and persistence pipeline with a bounded, read-only signed topology proposal at the semantic decision seam. C permits separately authored executable policies per character at that seam, including nonlinear history and context rules. All conditions preserve existing hard identity, value, commitment and disclosure decisions. This seam-level C is a feasible specialized comparator, NOT a universal specialized-organism upper bound. No training backend or actual model is available at preregistration. Thus this pilot alone cannot authorize a permanent architecture decision.

The whole-DUCK action/embodiment/learning track is reported separately. Do not add subject-policy results to DUCK-host results. A later integrated A/B/C comparison must resolve the audited missing ingress/decision/recall bridge while maintaining one committed trajectory. Calling say() and then executing a second DUCK decision is prohibited as an integration shortcut.

## Outcomes

Separate metrics: semantic action acceptability where a frozen rubric exists; cross-character action distinguishability; identity fields preserved; source UUID collision; relationship vectors over time; current decision history sensitivity; attributed episodic recall; negative recall; values; restart exact semantic continuation; mock renderer substitution; body feasibility; endogenous action; drive contribution; learning and prediction effects; raw outputs, repetition and diversity (offline diagnostics only); per-turn latency, process RSS, model calls, tokens, on-disk growth; source lines and authored parameter counts.

Naturalness, perceived coherence, recognizable character, ongoing life, authentic longitudinal quality, actual-model swap and transfer recognition are NOT inferred from deterministic success. Missing values are null with a reason, never 0 or 1. Hard identity/canonical/commitment/world/UUID failures are listed individually and veto promotion regardless of averages. Semantic distinguishability is not quality: arbitrary different choices can score high.

## Decision rule, fixed before complete results

No composite score. Report C minus A and C minus B separately on each applicable percentage scale and each character/split. A model-free pilot does not estimate human character quality. Graph adoption additionally requires B-A improvement on held-out history-conditioned behavior, causal graph ablation effects, no authority regression, and a complexity/performance advantage versus equally expressive simpler rules. Equality between B and C cannot establish noninferiority if C is weak, sample size is small, or the comparison is a narrow seam.

For a future confirmatory human study, primary outcomes are recognition, history-conditioned action coherence, value realization, and relationship trajectory. Use paired subject/scenario clusters (turns are not independent); stratify character, counterbalance A/B/C order and blind labels. Fix a 5 percentage-point noninferiority margin only after a separate blinded rubric/calibration pilot establishes it is smaller than an important perceived difference. Require multiplicity-adjusted one-sided 95% cluster confidence bounds below the margin for every primary dimension, plus no hard failures. An interval crossing the margin is inconclusive, not equivalence. A lower bound above 10 points in longitudinal quality is a signal to reopen the abstraction boundary. The 5/10 numbers are provisional engineering loss budgets, not psychological constants.

Human study starts with at least 30 independent scenario/history clusters per character and 3 raters per transcript, then uses pre-study power simulation with pilot rater/cluster variance to fix sample size. Do not collect until model digests, limits and rubrics are pinned. A separate mixed-model block tests same-character across-model distance against between-character within-model distance with names masked. Equal verbosity limits and tie options are required. Evaluator consent and recruitment are not fabricated.

## Stopping and scope gates

If no real backend exists, export blinded material and exact collection instructions, mark actual-model evidence unavailable and continue deterministic work. If B has no demonstrated meaningful advantage, do not create a mandatory package, replace .snp, or install learned graph deltas. Preserve a proposed representation and explicit migration map only. Origin translation with topology disabled must retain all unknown source fields and produce exact semantic parity. Authored graph influence never becomes memory, belief, world truth or permission.
