# Research Checkpoint: Expression Substrate Continuity

Date: 2026-08-31

This is a research-facing snapshot, not the engineering authority. Authoritative evidence is `persona_engine/evidence/mvi/EXPRESSION_SUBSTRATE_CONTINUITY.md`, its JSON evidence, and the test suite.

## Result worth preserving

Before this phase, renderer replacement was already prevented from changing canonical identity/trajectory, but different language backends did not receive one identical structured character moment. In particular, the Ollama expression path received primarily a prose workspace prompt rather than the explicit semantic decision, and the local-HF JSON expression prompt could not serialize a real `MemoryUnit`. The deterministic renderer also had no deliberate authored relationship-stance selection mechanism.

`expression-brief-v1` makes a JSON-safe noncanonical character moment the common realization boundary. A provider-neutral external callback can therefore drive ChatGPT-, Claude-, Grok-, or other host integrations without granting that model identity authority. The same phase adds optional cartridge-owned relationship-stance variants to the zero-model renderer. In the permanent probe, accumulated conflict versus accumulated positive treatment produced different Pretorius greeting behavior offline, while an offline renderer and a frontier-like external callback retained equal semantic projection for an identically developed character moment.

Targeted verification: `50 passed, 1 skipped in 0.86s`. Full deterministic suite: `354 passed, 1 skipped, 1 warning in 28.41s`.

## Potential thesis relevance

The phase sharpens a useful distinction between **behavioral continuity** and **expressive continuity**. Wayfarer can hold the behavioral/causal character state fixed while changing the linguistic substrate, then ask whether each substrate realizes a recognizable version of the same developed individual. This creates a cleaner independent variable for later renderer-substitution experiments than ordinary role-play prompting, where the model simultaneously supplies both character state and expression.

## Important limitation

The current evidence is Tier A and builder-designed. The external renderer used by the deterministic probe is a callback fixture, not an actual frontier-model evaluation. No claim should yet be made that users perceive ChatGPT, Claude, Grok, a local model, and the deterministic renderer as the same character. That question should be tested with frozen histories, real heterogeneous models, held-out prompts, and blinded human judgments.
