PersonaConsole Python Lab

Local human-testing console for Persona Engine. Internet is not required for mock mode or local Ollama testing.

Start Here

If the console is not already running, start it from this folder first.

1. Double-click the launcher

In File Explorer, double-click Start_PersonaConsole_Python.cmd. A terminal window will stay open while the local server is running.

2. Open the console

After the launcher starts, use the button below. If the page cannot be reached, the local server is not running yet.

Open Console Show Launcher File

A browser page cannot directly start a local program for security reasons. The launcher file is the safe Windows button for starting the offline local server.
